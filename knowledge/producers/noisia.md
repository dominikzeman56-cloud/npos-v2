# Noisia — Production Philosophy

**Knowledge source type:** `personal_observation` — derived from listening/pattern observation across known tracks, not yet processed through a formal Phase 0.5 course/interview Issue.

## Core Philosophy

"We treat every sound as a sonic weapon." Every element is processed to serve maximum effect; heavy layering is used, but each layer is engineered to have a distinct function — density stays controlled, not muddy.

## Decisions (actionable)

- Bass `body` design: heavy FM synthesis for harmonic content is a primary technique, not an occasional flavor. `[measured]`
- `noise`/texture layer: industrial noise layers used deliberately for texture and edge, separate from the body layer. `[measured]`
- Mixing treats individual mix elements almost like synth patches — multiple saturation stages and mastering-style processing applied per-element, not just on the bus. `[estimated]`
- Arrangement: longer drops (24–32 bars) with complex, multi-section build patterns — this is a deliberate deviation from shorter/simpler drop structures. `[estimated]`
- Mastering target: `loudness_strategy: controlled` leaning `crushed`, ~-5 to -4 LUFS, true peak ceiling around -0.5 dBTP. `[measured]`

## What NOT to copy

Don't copy the drop length (24–32 bars) into every track by default — it works because of the density/complexity Noisia builds into it; a sparser arrangement needs a shorter drop.

## Reference tracks

Stink, Tommy's Theme, Program, Stacked.
