# Bass Layer Separation

One layer = one function (BLUEPRINT §2 principle 4): `sub` | `body` | `movement` | `noise`.

## Principle

Bass is felt before it's analyzed. Build in this order, testing in the full mix at every step — never solo'd:

1. **`sub`** — fundamental, mono-compatible, must stay clear under the kick.
2. **`body`** — harmonic weight; gives the bass its perceived size.
3. **`movement`** — modulation/shaping; this is where reese-vs-growl decisions live (see BLUEPRINT §5 reese-vs-growl test).
4. **`noise`/texture** — grit or edge, optional, added last and sparingly.

## Checks (apply every session)

- Sub stays mono below 250 Hz (matches BLUEPRINT `stereo_global` rule).
- Kick and sub aren't masking each other — carve space, don't just add more sub.
- Mid-bass presence is intentional, not incidental buildup.
- Movement rate is a deliberate choice (grid-locked = growl, off-grid = reese), not accidental.

## Failure modes to catch

Muddy low-mids, weak/thin sub, kick-bass masking, unintentionally wide bass, static/lifeless movement.

## Confidence

`estimated` — this workflow order is a consistent pattern across sources, not measured from one specific track analysis.
