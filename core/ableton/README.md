# Šablona Ableton

**Jedna živá šablona: `NEUROFUNK_TEMPLATE_FINAL`** (Live 12.4.3, 174 BPM, 64 tracků, 5 returnů). Hotová; vynucuje pravidla fyzicky (skupiny, routing, sub mimo bass bus, dva MIDI spouštěče sidechainu, lokátory, limiter na masteru).

- **Kanonická specifikace** (kap. 1–17: architektura, routing, dogmata k ověření, pasti sestavování `.als`, lint spec) je ve vaultu `Hudební produkce\02 Šablona.md`.
- Soubor `.als` není v repu (velký binární stav, patří do Ableton projektu); repo drží jen specifikaci a lint pravidla.
- **Šablona se needituje bez souhlasu Architekta.** Změny pravidel jdou přes kánon (`02 Šablona`, kap. 13–14), ne přímo do `.als`.
- Generovat do `.als` jen routing, klipy a prázdné sloty. Plugin XML z cizích setů se nepřenáší (pády).

Dřívější verze tohoto souboru odkazovala na neexistující kandidátní šablonu `networkfunk-production-os`; ta je zrušená.
